# Simple Python Flask App

A simple web application built using **Python and Flask**.
The HTML, CSS, and JavaScript are included directly inside the Python file.

## Features

- Simple responsive app page
- Modern UI
- Button interaction
- HTML + CSS + JavaScript inside `app.py`
- No separate HTML/CSS files required

## Project Structure

```text
simple_app/
│
├── app.py
└── README.md
```

## Requirements

- Python 3.x
- Flask

## Installation

Open the terminal in the project folder and run:

```bash
pip install flask
```

## Run the Application

Run:

```bash
python app.py
```

You should see:

```text
* Running on http://127.0.0.1:5000
```

Open the following URL in your browser:

```text
http://127.0.0.1:5000
```

## How It Works

The `app.py` file contains:

- Flask application
- HTML structure
- CSS styling
- JavaScript button interaction
- Web route

Everything is contained in a **single Python file**.
